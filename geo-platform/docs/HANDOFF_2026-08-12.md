## 一、项目定位

GEO Platform 是一套基于真实 AI 检索、引用和内容证据，诊断品牌在生成式搜索中的信息进入瓶颈，生成可审计的干预候选，通过人工审核和真实实验验证效果，并持续沉淀 GEO 干预规律的决策与实验平台。

核心链路：`监测总览 → 决策诊断 → 最终策略 → 发布确认 → 固定复测 → 效果结论`

统一产品能力地图见：`docs/PRODUCT_CAPABILITY_MAP.md`

## 五、前端页面

| 功能区 | 页面 | 路由 | 能力边界 |
|---|---|---|---|
| 业务闭环 | 监测总览 | validation | 看品牌当前表现、引用完整度和采集质量；不产出最终策略 |
| 业务闭环 | 决策诊断 | recommendation | 解释单个问题的答案结构、引用资料、品牌状态和差距来源；可生成 Issue / Action / Experiment 草案 |
| 业务闭环 | 最终策略 | optimization | 唯一最终策略出口，承接证据包、策略候选、实验草案和人工确认 |
| 证据工作台 | 引用资料 | ranking | 以最终引用资料为主分析来源结构和页面价值；检索候选只做重合度旁证 |
| 证据工作台 | 证据标注 | golden | 审核回答主张、引用正文、URL 身份和段落对齐；不直接给最终策略 |
| 证据工作台 | 采集记录 | runs | 查看每次采集的状态、原答案、引用详情和原始证据文件 |
| 系统配置 | 问题配置 | config | 维护项目、Prompt、问题组和采集批次；一个 Prompt 就是一个用户问题 |

## 九、已知限制

1. **内容抓取**: 知乎/抖音/B站 反爬，自动抓取成功率约 50%，需人工补录
2. **负样本不可用**: Candidate↔Citation URL 重叠仅 3%，无法做 Cited vs Retrieved-not-cited 比较
3. **品牌页面不可用**: `/card` 抓取失败，Brand Gap 无法做内容级对比
4. **对齐精度**: 仅 L1 精确匹配有效 (15/180)，语义对齐 (L4) 未实现
5. **单 Prompt 单模型**: 排名无法跨 Prompt/Model 泛化
6. **Experiment #13**: 未执行任何真实实验
7. **Sampling**: 126 runs 中 87 条为 CONTEXTUAL_SESSION，不可作为独立样本
8. **决策诊断 V1**: 当前为规则抽取和外显引用归因，不推断模型训练语料，也不自动发布内容
9. **用户语言约束**: 面向目标用户的界面必须使用中文；内部表名、API 和工程枚举可保留英文
