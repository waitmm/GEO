# 采样任务与累计样本池

文档编号：PRD-SAM。里程碑：M1。版本：2026-09-30。实现状态：未核查。

业务依赖：PRM。共用规则见 [数据与状态契约](16_共用契约与状态.md)。

## 目标与范围

用户选择已接入的平台、次数和采样配置，获得可回溯的真实答案。采样记录长期累积；单次失败可显式重试。2026-10-09 基础每日调度纳入本版，复杂调度及其他采集平台后置。

每日计划冻结 Prompt 文本、平台、独立会话方式、数量及 hash，显式保存时区、当地时间和授权总尝试上限。每次触发原子预留次数和创建正式 Analysis/Run，失败也计入；不自动重试，不补跑停机期间所有错过时隙。修改问题、登录/验证码/会话隔离错误暂停后续触发。暂停后 worker 不启动排队会话；已运行会话保留真实结果。恢复需新建明确授权计划，不能重置旧计划用量。

实现：`scheduling.py`、release worker、`sampling-schedules` API、Monitor 的“持续采样计划”。调度工程测试使用隔离库/测试时钟，不等于真实跨日采样验收。

## 页面和主要操作

采样启动面板展示平台、入口类型、目标次数及预计调用说明。任务页展示计划数、已完成、失败、等待和取消情况。Run 明细展示问题、答案、采样时间、引用、已具备的截图或原始响应及错误详情。

## 正常流程

1. 读取项目可用采样能力，用户选择平台和目标次数。
2. 创建任务并显示明确运行状态；已有有效样本仍可查看。
3. 每个逻辑 Run 保存答案与原始出处；引用进入来源获取流程。
4. 失败重试关联原逻辑 Run 的 attempt；不会凭空增加独立有效样本数量。
5. 追加采样产生新的逻辑 Run；保留旧结果供选择和比较。

## 输入输出与业务字段

| 字段/对象 | 要求 | 语义 |
|---|---|---|
| sampling_job_id / logical_run_id | 系统生成 | 任务与逻辑样本身份分开 |
| attempt_id / attempt_no | 每次尝试生成 | 重试不自动成为额外统计样本 |
| platform / collection_surface | 必需 | 网页端、API 等不能混称为同一种采样条件 |
| prompt_version / config_snapshot | 必需 | 联网模式、地区语言等保存可得信息；未知如实记录 |
| answer_raw / collected_at / citations[] | 成功时必需 | 原始内容保留，不以整理稿覆盖 |
| collection_status / error_code | 系统记录 | 区分失败、取消、等待授权和限流 |

以上是业务信息要求，真实表和接口复用映射由 M0 完成，不强制按字段新建一套模型。

## 需求与规则

| 需求编号 | 行为要求 | 可观察标准 |
|---|---|---|
| SAM-001 | 采样成功必须有合法答案；合法答案不必包含品牌或引用。 | 无品牌无引用可以是有效观察。 |
| SAM-002 | API 与网页采样单独标识并在比较时校验。 | 不能把不同入口的结果静默汇总成同口径趋势。 |
| SAM-003 | 重试复用逻辑样本身份并保留尝试记录。 | 分母按选定逻辑样本而非请求次数计算。 |
| SAM-004 | 凭证缺失、限流和技术失败应给出实际原因。 | 等待授权不是计算失败；缓存缺失不是采样失败。 |

## 状态和异常

任务：QUEUED → RUNNING → SUCCEEDED / PARTIAL / FAILED / CANCELLED。
独立等待状态用于凭证或外部条件，必须有具体原因和恢复动作。重试和退避预算由开工核查现有实现后配置化，不允许无限调用。取消应停止新请求，并保留已完成样本。

## 验收场景

| 用例 | 需求 | Given | When | Then |
|---|---|---|---|---|
| AC-SAM-01 | SAM-001 | 平台返回完整答案但没有目标品牌 | 保存 Run | 采集成功，品牌观察为未出现。 |
| AC-SAM-02 | SAM-003 | 一条采样失败 | 仅重试该逻辑 Run | 成功结果只计一个样本，其他 Run 不重采。 |
| AC-SAM-03 | SAM-004 | 任务有部分完成 | 取消剩余任务 | 已完成数据保留，状态与数量准确。 |
| AC-SAM-04 | SAM-002 | 网页与 API 各有样本 | 查看趋势和范围选择 | 展示入口区别，不默认完全可比。 |
| AC-SAM-05 | SAM-004 | 采样凭证缺失或平台限流 | 启动/恢复任务 | 显示等待原因和恢复操作，不伪装采样结果，也不无限请求。 |

各场景初始状态均为 NOT_RUN。验收结果填写到 [验收矩阵](17_验收矩阵.md)，不得因文档齐全就标为通过。
