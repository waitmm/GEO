# Citation Contribution 引用贡献分析

文档编号：PRD-CIT。里程碑：M2。版本：2026-09-30。实现状态：未核查。

业务依赖：ANS、SRC。共用规则见 [数据与状态契约](16_共用契约与状态.md)。

## 目标与范围

判断答案单位与来源片段的内容对应和证据关系，明确引用正文解释得了什么、解释不了什么。低匹配应产生策略输入，而不是关闭策略生成。

## 页面和主要操作

引用详情呈现答案单位、候选 passages、来源角色、对应关系、支持或冲突以及定位依据。区分“答案附有引用”和“正文支持该表述”。未评估项显示未评估。

## 正常流程

1. 只在当前分析可用来源及明确补充资料中召回候选。
2. 复用现有检索与缓存能力，结合显式锚点、相关性和来源差异选择候选。
3. 判断内容对应、支持/冲突/相关/无关关系及适用范围。
4. 无法取得正文或未完成判断的关系保留 UNKNOWN/NOT_EVALUATED。
5. 把可用支撑、支撑缺口和观察到的平台信息分别传入策略。

## 输入输出与业务字段

| 字段/对象 | 要求 | 语义 |
|---|---|---|
| answer_unit_id / passage_id / snapshot_id | 必需 | 所有关系定位到冻结输入 |
| content_correspondence | 语义输出 | 对应程度不等价于支持 |
| evidence_relation | 枚举 | SUPPORTS / CONTRADICTS / RELATED / NONE / UNKNOWN |
| anchor / observed_citation | 独立字段 | 原答案显式引用锚点与后续语义推断分开 |
| generation_influence | 默认不可确认 | 缺少直接可观察证据时保持 UNKNOWN |
| evaluation_status / coverage | 必需 | 未评估不是 NONE |

以上是业务信息要求，真实表和接口复用映射由 M0 完成，不强制按字段新建一套模型。

## 需求与规则

| 需求编号 | 行为要求 | 可观察标准 |
|---|---|---|
| CIT-001 | 来源角色与证据关系分开存储。 | 补充官网资料可支持事实，但不能冒充原答案引用来源。 |
| CIT-002 | 内容相似、支持关系和生成因果不得互相替代。 | 有相似文字不等于模型因此选择品牌。 |
| CIT-003 | 不新增每条理由固定相同片段数的硬编码。 | 按已验证召回策略、相关性和预算控制，不能为凑数引入无关片段。 |
| CIT-004 | 引用支撑低时产生答案需求与支撑缺口输入。 | 不能把 NONE/UNKNOWN 全部转成无优化资格。 |

## 状态和异常

关系任务：未评估、处理中、已完成、失败。关系值仅在评估完成后确定。正文不可取与正文已取但不支持必须分开说明。聚合统计同时返回各类关系及未覆盖数。

## 验收场景

| 用例 | 需求 | Given | When | Then |
|---|---|---|---|---|
| AC-CIT-01 | CIT-002、CIT-004 | 答案谈能力 A，引用只有泛介绍 | 分析关系 | 返回低对应或 RELATED/NONE，并仍提供可行动的支撑缺口。 |
| AC-CIT-02 | CIT-002 | 有引用观察但来源无法取得 | 分析 | 保留引用平台，证据关系 UNKNOWN；不假装 NONE。 |
| AC-CIT-03 | CIT-001 | 非原引用官网支持该事实 | 展示证据 | 事实可消费，但原答案引用统计不增长。 |
| AC-CIT-04 | CIT-002 | 部分关系尚未处理 | 显示统计 | 未评估单列，不混入 NONE 或支持率分母。 |
| AC-CIT-05 | CIT-003 | 两条理由分别只有一个相关片段和多个相关来源 | 进行召回 | 不为凑固定片段数加入无关内容；候选由相关性及已声明预算决定。 |

各场景初始状态均为 NOT_RUN。验收结果填写到 [验收矩阵](17_验收矩阵.md)，不得因文档齐全就标为通过。
