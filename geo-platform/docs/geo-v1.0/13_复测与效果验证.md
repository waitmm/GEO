# Validate 独立变化比较

文档编号：PRD-VAL。里程碑：M3。版本：2026-10-09。实现状态：独立比较 API 与共享指标已接入，浏览器及真实新采样验收待完成。

业务依赖：MON、SAM。不依赖 PUB 或执行确认。共用规则见 [数据与状态契约](16_共用契约与状态.md)及 SC-DELIVERY-001。

## 目标与范围

用户明确选择同一项目、同一 Prompt 的两个不重叠范围，返回与 Monitor 一致的基础指标和引用变化。不要求发布、干预或人工语义审核。未知模型/会话条件保留限制，重要条件缺失或冲突不显示可比增幅；不能从观察变化推导生成因果。

## 页面和主要操作

Validate 展示基线与对照范围、可选精确 Answer 版本、目标 URL、采样条件。并排显示 n/N、有效/计划数、百分点和新增/持续/未再观察到的引用。语义未算不按零计算；历史比较可刷新恢复。发布登记是可选扩展，不作为入口。

## 正常流程

1. 选择两个明确 Context 和 raw hash，绑定同一品牌身份快照和指标版本。
2. 后续样本来自同一采样池；新采样另按明确平台、数量和授权执行，不要求发布后才能运行。
3. 采样形成新的 Run，固定本轮复测范围；不把失败后的额外请求当独立成功样本。
4. 用同口径计算基础指标；版本不同时显式重投影两侧或标为不可直接比较。
5. 按可得证据输出观察结论与限制，允许继续下一轮。
6. 保存全部实验记录供后续学习，包括无变化、负向和不可评价结果。

## 输入输出与业务字段

| 字段/对象 | 要求 | 语义 |
|---|---|---|
| result_version / input_hash | 必需 | 比较输入身份，重复请求复用；无 publication_id 前置 |
| baseline_scope / retest_scope | 必需 | 不可静默挑选有利样本 |
| target_metrics / observation_window | 必需 | 显式样本范围及时间；不承诺生效时间 |
| comparability / configuration_differences | 系统检查 | 平台入口、Prompt、时间、规则版本等 |
| before_after / coverage / citation_changes | 系统生成 | 指标差与来源采用观察分开 |
| outcome / limitations / next_observation | 必需 | 支持观察、削弱假设、暂无变化、数据不足等 |

以上是业务信息要求，真实表和接口复用映射由 M0 完成，不强制按字段新建一套模型。

## 需求与规则

| 需求编号 | 行为要求 | 可观察标准 |
|---|---|---|
| VAL-001 | Validate 复用 Monitor 的指标实现。 | 同输入同版本必须返回相同基础计数。 |
| VAL-002 | 前后不一致时展示差异，不伪装可比。 | 可以继续展示原始观察，但不做无依据效果结论。 |
| VAL-003 | 单次 0/9→1/9 报告为增加 1 次、约 11.1 个百分点。 | 不能自动宣布策略有效；也不能称增长无限百分比。 |
| VAL-004 | 页面被引用是直接来源观察，不等于完整推荐因果证明。 | 重复、对照、引用采用是不同证据维度。 |
| VAL-005 | 1.0 保存所有实验，不自动推广策略规则。 | 不把两轮正向、固定显著性或固定天数写成通用成功门槛。 |

## 状态和异常

复测任务复用采样任务状态；评价结果独立为 OBSERVED_CHANGE、NO_CLEAR_CHANGE、INSUFFICIENT_DATA、NOT_COMPARABLE 等。结果不是互相替代的单一因果等级，可同时存在引用采用与数据不足。

## 验收场景

| 用例 | 需求 | Given | When | Then |
|---|---|---|---|---|
| AC-VAL-01 | VAL-003 | 基线 0/9，复测 1/9 | 生成报告 | 正确展示计数和百分点，描述本轮观察，不自动判定策略有效。 |
| AC-VAL-02 | VAL-002 | 基线网页端，复测 API | 比较 | 提示条件变化，不输出无条件的同口径提升。 |
| AC-VAL-03 | VAL-004 | 无发布记录，对照范围观察到新 URL | 比较 | 记录相对基线新增，不称收录或策略成功；基线引用不完整时保持未知。 |
| AC-VAL-04 | VAL-005 | 一轮效果下降 | 保存和查看实验历史 | 保留真实结果，不剔除以美化规则效果。 |
| AC-VAL-05 | VAL-001 | 相同范围与相同指标版本 | 分别在 Monitor 与 Validate 查询 | 计数、分母、未知处理一致，只有展示上下文不同。 |

各场景初始状态均为 NOT_RUN。验收结果填写到 [验收矩阵](17_验收矩阵.md)，不得因文档齐全就标为通过。
