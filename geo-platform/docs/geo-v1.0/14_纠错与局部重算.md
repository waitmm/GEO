文档编号：PRD-COR。里程碑：M2。版本：2026-10-10。实现状态：部分实现/隔离验证；对象级事实及关系纠错的完整产品验收尚未完成。

当前已有：BASIC 和补充公开资料的显式版本选择、旧任务冻结输入不变；稿件编辑形成独立文本 QA 任务，不重跑 Answer/Citation；阶段恢复复用已保存对象和合格缓存。相关证据见任务台账、浏览器040336Z/040802Z及 worker-process-fix-20261010。资料更新不是品牌事实纠错的等价验收，稿件改写也不是修改关系判定；下面尚未覆盖的对象级纠错要求继续有效。

2026-10-10 增量：自动任务的“纠正品牌事实”提供单项事实、状态、出处、纠错依据及受影响/不受影响方向预览。操作者明确确认后保存独立追加版本，不修改原事实或机器结果。表级 UPDATE/DELETE 被拒绝；请求绑定原事实 hash、当前事实集合 hash、预览 hash 和操作者，陈旧输入/伪造 actor 被拒绝。

“更新受影响内容”进入现有自动队列，冻结原品牌/Prompt/回答/来源，仅替换被纠正事实。回答、引用与资料核实只允许兼容缓存，不能借稿件预算重新外调；只有受影响稿件生成/QA可另行授权。原能力方向不成立时，沿用既有资格规则选择已有的其他合格候选、探索方向或不生成，不扩大召回和当前单方向选择上限。纠正未选中事实且原方向不受影响时，无新稿、无新增模型调用；页面显示“纠错已应用，无新增稿件”。未受影响稿件继续从原任务查看；受影响原稿仅作为历史版本保留，不继承新资格。没有事实的空态不阻止查看稿件。

业务依赖：OPT、TRU。共用规则见 [数据与状态契约](16_共用契约与状态.md)。

## 目标与范围

用户可纠正答案归属、证据关系、品牌事实和资产信息。人工输入是增强与纠错，不是机器链必经审批。每次改变明确影响范围，保留旧结果并生成新投影。

## 页面和主要操作

2026-10-12 资产信息增量：从当前方案详情修改资产操作及核查信息，保存为独立执行结果版本。表单明确说明仅发布位置确认受影响，稿件及原始证据不变；用户报告不升级为系统已核实。旧版只读、陈旧提交拒绝，实际正文编辑仍须独立文本QA。它覆盖方案内资产信息补充，不代表全局资产盘点或答案/关系纠错已完成。

各结果详情提供“纠正/补充”操作；表单展示原判断、用户修改、依据和影响预览。提交后显示重算任务、可继续查看的旧版本及新版本入口。

## 正常流程

1. 在具体对象上补充事实、来源或纠错。
2. 校验项目归属、原版本和证据类型；不把任意用户文本自动视为已验证真相。
3. 计算受影响的投影：例如品牌事实改变触发相关策略和稿件检查。
4. 复用未受影响的答案、来源快照和分析缓存。
5. 生成新版本，展示更改摘要；已发布和已复测的历史记录继续绑定原版本。

## 输入输出与业务字段

| 字段/对象 | 要求 | 语义 |
|---|---|---|
| correction_id / target_object / base_version | 必需 | 定位修改对象 |
| correction_type / new_value / source_refs | 必需或按事实需要 | 补事实、纠错、补资产等 |
| provenance / actor / created_at | 系统记录 | 保留人工来源与时间 |
| impact_manifest / recompute_job_id | 系统生成 | 说明受影响对象与阶段 |
| supersedes_version | 生成时记录 | 旧版本保留可追溯 |

以上是业务信息要求，真实表和接口复用映射由 M0 完成，不强制按字段新建一套模型。

## 需求与规则

| 需求编号 | 行为要求 | 可观察标准 |
|---|---|---|
| COR-001 | 没有人工纠错仍可完成整个流程。 | 未 review 不能作为所有策略的硬阻断。 |
| COR-002 | 事实、判定纠错和编辑草稿分别处理。 | 纠正一个品牌别名不应清空所有正文快照。 |
| COR-003 | 局部重算以依赖关系为准，不是全库扫描。 | 跨项目和无关 Prompt 不重新外调。 |
| COR-004 | 历史发布与复测保持原版本绑定。 | 新事实不静默改写既有实验结论。 |

## 状态和异常

SUBMITTED → APPLYING → APPLIED / CONFLICT / FAILED。并发修改基于版本进行冲突提示，不能覆盖他人或另一个任务的新结果。失败显示可恢复原因；旧可用结果继续可见。

## 验收场景

| 用例 | 需求 | Given | When | Then |

各场景初始状态均为 NOT_RUN。验收结果填写到 [验收矩阵](17_验收矩阵.md)，不得因文档齐全就标为通过。
