## 来源与效力

本包依据 2026-09-30 上传的产品架构文本及本轮后续对话。后续用户明确修正优先于初始文档和早期建议。本包不采用未经证实的竞品独占能力、市场规模或统一内容字数作为开发依据。

## 本次补齐的执行默认值

以下是将已确定方向落地所需的产品细则，尚未声称经过现有代码验证。M0 若发现与已有正确语义冲突，应局部对齐并记录，不重新开启全局架构讨论。

| 项目 | 本包默认 | 核查后允许调整的范围 |
|---|---|---|
| 指标集合关系 | Recommendation ⊆ Option ⊆ Mention，保留原始事件 | 与现有正确分类对齐并统一版本，不能各模块不同口径 |
| 机会展示 | 建议优化/值得观察/暂不优先，附原因 | 文案与排序可随界面调整，不引入无校准分数 |
| 状态名称 | 各 PRD 的语义集合 | 可以复用现有名称，但必须映射且不混淆维度 |
| 任务与版本 | 明确身份、幂等、旧结果可查看 | 复用现有表与接口，不强制新建一套 |
| 页面组织 | 三个主模块与 Prompt 三 Tab | 适配当前路由和组件，不强制换技术栈 |
| 导出形式 | 具体稿件可复制/导出 | 先实现现有可用文本格式，不要求多格式导出平台 |

## 开工核查清单

- 当前仓库分支、未提交改动和 AGENTS.md。
- 真实生产/本地运行入口、迁移版本与数据库设置。
- 可复用采样、抓取、召回、缓存、策略、QA 和复测入口。
- 旧状态依赖，以及既有范围选择和结果版本机制。
- 已接入平台与模型、实际可用配置、授权和费用边界。
- 当前指标定义、用户身份边界和项目隔离。
- 可用验证样本、测试命令、日志与实际任务耗时。
- 当前可用发布资产、复测记录及真实闭环验收条件。

这些是查代码和查配置的工作项，不是要求用户重新提供一套产品设计。实现文件、负责人姓名、工期和上线时间在证据不足时留空，不能凭空补齐。

## 变更规则

真实运行错误、交付阻断或明确范围冲突可以重开对应条目。变更需记录原因、影响需求/任务/用例、旧结果处理和验收方式。其他新增想法进入后续版本清单。

变更记录初始条目：2026-09-30，建立本次文档基线；实现未核查，测试未运行，无软件通过声明。
