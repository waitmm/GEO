# 页面交互与异常反馈

本文补充各 PRD 的可观察界面行为，复用现有组件与路由。实际像素设计、组件名与接口路径由开发对照仓库确定，不另建一套设计系统。

## 已采用的实现规范

- 方案内资产核查与正文分区；新建和更新使用同一“最终资产操作”选项，未知状态不默认新建。更新展示页面URL、标题、版本和权限依据；新建展示完整盘点确认。复选项不预选，修改事实输入后撤销已勾选确认。保存生成明确版本，历史表单只读；缺失业务信息不遮挡正文。提示必须区分用户报告和系统验证，窄屏字段换行，键盘可操作。
- 稿件详情的输入、选择和章节勾选须有可访问名称，不能仅有相邻视觉文本。青色状态和正文链接沿用既有色系但提高文字对比度；全页axe不豁免旧控件。官方资料路径121711Z已通过新增检查与390px截图，未自动判断项仍单列。
- 保存策略/稿件的精确读取不依赖当前资格投影先成功。资格接口失败保留稿件，显示独立错误与重试；资格为空不能授权新策略生成。策略对象自身404/归属不符仍拒绝，不回退为新建或最新稿件。请求继续绑定项目、问题、分析与代次。

- 项目配置的保存预览使用服务端同一归一化和校验，不另写前端品牌规则。改输入立即撤掉旧预览，过期响应不得覆盖；空域名与已配置未核实分开。编辑回填原地区/语言，保存失败保留输入并显示错误；在途提交锁定表单。浏览器105120Z已验证无效URL恢复、别名去重和非默认地区/语言保留。
- 已有明确分析时，固定范围摘要、自动优化任务与交付先显示，采样池和技术版本记录折叠。无分析时采样池展开；运行中的采样状态不折叠。1440/390主操作须在首屏内，不让技术ID占据主要操作路径。窄屏导航子内容固定宽度，收起时隐藏，避免动画中被挤成竖排；截图在布局稳定后保存。

- 基础组件沿用Ant Design，图标沿用Lucide，语言包为zh-CN。主导航按Monitor、Optimize、Validate、品牌资料、配置组织；技术hash/内部JSON仅在折叠审计详情。
- 既有样式：页面背景`#f3f5f8`、正文`#1f2937`、白色内容面，边界`#dce3ee`；使用既有成功/警告/失败组件并配文字，不仅靠颜色。以上实现在`frontend/src/styles.css`，对比度仍需逐控件实测。
- 页面标题使用组件的24px层级，正文沿用14px基准；间距以8/12/16/24px为主。工具按钮固定大小、提供中文名称，文字按钮用于明确动作；不把内部枚举当操作说明。
- 768px以下折叠侧栏，header换行并随滚动固定，导航按钮不得脱离页头压住表单；项目与Prompt选择器不撑出屏幕。浏览器043444Z验证390px滚动592/630/875px时按钮仍在页头范围内，保留几何断言。宽表局部横向滚动，不截断数据，不令页面整体横向漂移。正文、长URL允许换行。
- 异步查询绑定项目/Prompt/页面代次。切换或卸载后旧请求结果不更新新页面；加载失败可重试，表单输入保留。刷新保留明确URL对象身份，不从其他项目恢复任意latest。
- 优化任务选择写入URL；已明确选择的旧任务在轮询、刷新后不变。精确稿件链接同时匹配方案和结果版本；无效或跨范围身份显示未匹配，不偷偷展示最新稿件。任务切换期间不短暂显示另一任务的旧正文。history-053022Z已复检旧稿刷新，其他分支继续由正式浏览器路径验收。
- 品牌资料按项目而非Prompt维持编辑表单。同项目切换问题不得清掉未保存输入，切换项目必须隔离；浏览器040336Z已验证前者。补充公开URL获取与内部BASIC文本分开，获取需显式授权，不自动变成原回答引用或已核实能力。
- 原文、来源、内部限制及稿件分区。复制和Markdown导出面向已保存正文，不能夹带内部审计；浏览器043444Z已验证键盘触发及剪贴板/下载文件逐字一致。导出文件名包含结果版本并清理路径/控制字符；界面仅提示下载已发起，不假称已发布或已保存到用户磁盘。
- 保存/复制通知使用已挂载的Ant App上下文，避免React19静态消息调用失效。请求60秒截止覆盖响应体读取；超时说明可能已经受理，先刷新核对，不自动重复提交。调用者取消仍保留取消语义。
- Optimize 默认展示自动任务、建议、正文和实际 QA；高级资料/纠错/审计按需展开，精确历史诊断链接保持展开。轮询单次在途，避免慢响应被后续轮询永久作废。V2 读取按项目、Prompt、分析与请求代次验证归属，旧请求不得写回新页面或地址栏。
- 浏览器验收保留1440/1024/390截图与trace。键盘Tab、Enter、Esc、焦点回归、对比度为必需独立检查，不用截图代替。
- 已接入本地 axe-core 检查 WCAG A/AA 相关规则，完整结果及未能自动判断的项目均保存。不能将零自动违规称为全面 WCAG 认证。对比度使用实际渲染颜色；不关闭失败规则。窄屏表格滚动区提供键盘焦点及列名，测量副本不进入焦点序列。选择控件、行选择和采样次数均有中文可访问名称。
- 自动稿件任务在开始文本检查前持久化“文本 QA”阶段，不能始终显示“生成稿件”；命中缓存也要保持真实阶段。业务 worker 控制阶段，模型传输层不另行推断业务状态。
- 批量问题使用独立多行输入，逐项反馈并保留失败输入；成功项锁定，下一次仅提交待处理项。窄屏导航提供中文命名的键盘展开/收起按钮、Escape焦点回归，选页后收起。弹窗使用与正文同等的对比度要求，不假定门户节点继承页面样式。

官网与私有页面适用性见 [SEO/GEO规范](SEO_GEO_STANDARD.md)，实际结果见 [检查报告](SEO_GEO_REPORT.md)。

## 关键操作

| 页面/操作 | 操作前 | 处理与完成反馈 | 异常/恢复 |
|---|---|---|---|
| 创建项目 | 必填品牌名/项目名校验，域名可留空 | 成功进入项目，显示下一步添加 Prompt | 保存失败保留输入；不能生成重复项目 |
| 批量添加 Prompt | 展示待添加条目与精确重复提示 | 返回逐项结果，已有项可以直接进入 | 某条失败不让已成功条目重复提交 |
| 开始采样 | 展示平台/入口/次数与现有可用配置 | 返回任务身份，任务页显示实际完成量 | 凭证缺失、限流和失败显示不同原因及操作 |
| 查看 Monitor | 筛选范围与指标版本明确 | n/N 与覆盖并列，明细可跳原文 | 分母 N=0 显示暂无有效数据；分母有效、分子 n=0 显示 0/N |
| 点击分析优化 | 默认明确选择集，显示 Run 数和时间 | 提交后冻结范围，显示自动阶段进度 | 无有效答案提示先取得合法输入；无知识库不禁用 |
| 继续分析 | 当前分析任务存在 | 从原范围恢复，复用已完成部分 | 不自动重采样，不改选最新 Run |
| 来源补录 | 打开具体来源对象 | 生成新快照，说明受影响范围 | 验证页内容拒绝，其他有效资料继续消费 |
| 查看行动 | 每项显示问题依据、具体动作、渠道与验证目标 | 打开实际稿件或修改方案 | 某项需改写时显示处理进度，其他可用项继续可见 |
| 编辑执行稿 | 当前稿件与版本可见 | 保存为新版本并自动检查差异 | 未检查的新事实不继承旧公开资格；旧合格版本仍可看 |
| 复制/导出 | 交付正文与执行说明分区 | 复制内容对应选定版本，给出完成反馈 | 技术 ID、内部待核实占位不混入正文 |
| 发布登记（本版非必需） | 保留已有可选历史功能 | 不控制主导航和稿件资格 | 未发布不能阻止监测或比较 |
| 变化比较 | 展示明确基线/对照范围和采样条件 | 保存版本、复用指标、显示变化 | 失败不算缺席，条件差异不可比；不要求发布 |
| 每日采样 | 展示时区、时间、数量和总尝试授权 | 开启、暂停、下次执行、剩余次数 | worker 未运行不伪称正在采集；访问阻断暂停 |
| 纠正事实/判定 | 打开具体对象与当前版本 | 展示影响范围并局部重算 | 基于过期版本提交时提示冲突，不覆盖较新结果 |

## 共用界面状态

- 空态：说明缺少什么以及一个明确下一步；不要显示虚构示例数据冒充真实结果。
- 加载：展示对应项目/Prompt 和阶段，已有结果仍可阅读；不要用无限旋转代替任务状态。
- 部分完成：显示完成数、未覆盖数和原因；部分结果不能标全集完成。
- 真实零值：明确 0/N，并能查看所有已完成样本。
- 失败：可读原因、影响范围及恢复操作；重试只处理失败对象。
- 等待外部条件：说明所需配置或条件，与程序失败不同。
- 旧版本：明确版本和范围；默认当前选定上下文，不静默跨 Prompt 回填。
- 操作中：防止重复提交，刷新后从服务端恢复；返回成功以持久化结果为准。

## 文案原则

### 可选事实纠错

已有任务直接进入“纠正品牌事实”，展示该任务冻结的事实与后续纠错历史；不要求每个用户进入。先填写事实/条件、判断、出处、依据并预览影响，再由用户明确勾选保存，不能默认同意。保存和更新受影响内容为两个明确命令；旧稿始终可读。后续版本冲突、空事实、读取失败分开展示。判断下拉使用原生 select，避免 Form 注入 ARIA 属性到无对应角色的包装节点。桌面及390px自动检查与截图证据为054853Z，自动工具未裁定项不算人工通过。

“当前完成 3/9，以下指标基于已完成 3 条”优于只写“分析完成”。
“引用正文暂不可取，已基于答案需求与引用平台生成探索方案”优于“证据不足，无法优化”。
“该表述缺少依据，系统正在调整稿件”优于把整个计划显示为“不可发布”。
“本轮从 0/9 增至 1/9，尚不足以确认策略效果”优于“推荐率显著提升”。

这些是界面语义要求，最终短文案可按现有产品风格调整，不能改变其真实性。
